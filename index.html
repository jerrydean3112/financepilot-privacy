1. What FinancePilot is

FinancePilot is currently a limited beta expense-management assistant. It helps business travelers organize receipts and expenses and prepare a reviewable expense report.

FinancePilot is prerelease software. Features, practices, and this notice may evolve.

2. Information FinancePilot may receive

Google account and Gmail

Users may connect a Google account.

FinancePilot currently requests read-only Gmail access (gmail.readonly) so it can identify messages likely to contain receipts, travel confirmations, and other expense-related information. This Google permission can read mailbox content; FinancePilot uses it for those expense-management purposes.

FinancePilot does not use Gmail authorization to send, modify, or delete email.

Relevant information from connected Gmail may include merchant, amount, transaction date, receipt information, travel information, and other information needed for expense management.

Optional Google Calendar

FinancePilot may also offer optional read-only Google Calendar access to help organize trips and suggest business context. Calendar access is separate from Gmail, is not required to use Gmail import, and is not used to create or modify calendar events.

Outlook / Microsoft 365

Users may connect one work Outlook / Microsoft 365 mailbox.

That connection uses Microsoft Graph with delegated, read-only mailbox and calendar permissions:

  • Mail.Read — read inbox messages and attachments so FinancePilot can identify receipts, travel confirmations, and other expense-related information.
  • Calendars.Read — read calendar events in a rolling window of about the previous 30 days and the next 90 days, as contextual evidence for trips and expenses.

The same connection also requests the existing sign-in permissions openid, profile, email, offline_access, and User.Read, so FinancePilot can identify the mailbox and refresh access. It does not request Mail.ReadWrite, Mail.Send, or Calendars.ReadWrite.

FinancePilot does not use these permissions to send, modify, or delete Microsoft email, or to create or modify Microsoft calendar events. Microsoft Graph calls for this feature are read requests.

Relevant receipt, travel, and expense information from connected Outlook mail may be processed for FinancePilot functionality, including expense discovery, evidence extraction, trip association, review, Prepared Reports, and supporting evidence.

Calendar information is contextual evidence. It helps explain trip and expense timing and business context. It does not automatically create an expense, and it is not used to change the user’s Microsoft calendar. Calendar permission can be missing while the mailbox stays connected. Outlook mail import does not require Google Calendar.

Before calendar information is shown or used for that context, event descriptions are omitted. Events Microsoft marks private or confidential are minimized further: the title is Busy, and location, organizer, and attendees are omitted. Cancelled events are not imported. An on-device cache may still hold synced calendar fields, including a private event’s title, location, and attendees. Minimization is applied when FinancePilot shows or uses those events; it does not rewrite that cache. Event descriptions are not written into that cache.

Information you provide

Users may also provide receipt images, corrections, business purposes, attendees, confirmations, and other expense-related information.

Voice commands (optional)

If you use optional push-to-talk coworker voice commands, FinancePilot requests microphone and speech-recognition permission. Audio is captured so that speech can be turned into text. FinancePilot does not request on-device-only recognition. Apple’s speech recognition service may process the audio off this device. FinancePilot does not send that recording to OpenAI or to Google Gemini.

After you confirm the recognized text, that text can be included in an AI Coworker request described in §3B. It is sent as text, not as audio. Recognized text is shown before a coworker action that uses it.

3. How information is used

Information is used for user-facing FinancePilot functionality, such as:

  • expense discovery
  • evidence extraction
  • trip association
  • review
  • Prepared Reports
  • supporting evidence
  • optional Ask FinancePilot analysis and preparation assistance (when you consent, as described in §3A)

FinancePilot may use AI services to analyze information for those user-facing purposes.

When FinancePilot extracts fields from a receipt image or from receipt text, it sends that image or text to Google Gemini (Gemini 2.5 Flash) through a FinancePilot server. That send can include the receipt image or the receipt text. It is separate from the minimized Ask observation and from AI Coworker, and it is not sent to OpenAI. FinancePilot has not independently verified how long Google keeps those extraction requests.

Google user data is not sold and is not used for advertising.

FinancePilot’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including Limited Use requirements.

Information FinancePilot receives, including Microsoft account, mail, and calendar information, is not sold and is not used for advertising.

3A. Optional AI expense analysis and preparation (Ask FinancePilot)

With your explicit, revocable consent, FinancePilot may send a minimized expense observation through a FinancePilot server for read-only analysis and proposals (Ask FinancePilot). The server selects one provider for that request. The default is OpenAI (GPT-4o mini) when that credential is configured, and Google Gemini (Gemini 2.5 Flash) otherwise. A server setting can force one of those two providers. This notice does not state which setting is in force on a particular day.

That observation may include the expense id, the merchant, the amount, a confirmed currency only when one is already recorded, a currency hint, an evidence id and kind, and open requirements. It does not include email bodies, receipt images, attachments, OCR text, or payment details. This exclusion describes the Ask observation only. It does not describe AI Coworker tool results in §3B.

Eligible expenses include expenses imported from Gmail and Outlook accounts connected to your FinancePilot account.

On the Ask FinancePilot path described above, the model is not given a write tool. A business-purpose change on that path still requires your Approve. That sentence does not describe AI Coworker. AI Coworker is described in §3B. The older Action Framework is not the path AI Coworker uses to save a business purpose or a classification. Where a preparation action is still offered for your approval, FinancePilot may perform it only after you allow it:

  • after you Approve, for actions that require confirmation (for example, adding a business purpose); or
  • for a narrow allowlist of reversible evidence-organization steps that do not require per-action Approve when identity is unambiguous (for example, linking already-verified receipt evidence).

Authorized Action Framework executions may create audit records of what was proposed, approved or auto-allowed, and applied. Where the product supports it, those preparation steps may be rolled back.

When the Ask provider for that request is Google Gemini on Google’s paid Gemini API, Google’s published terms state that prompts and responses are not used to improve Google products. This notice does not claim that optional Google developer log datasets are shared or unshared with Google; that project setting is separate. Google may still keep prompts and responses for a limited time to detect abuse and to meet legal requirements, and may store or cache them in any country where Google or its agents maintain facilities. FinancePilot does not claim a specific Google retention day count. FinancePilot’s own operational log for this review records proposal type, confidence, and evidence count — not the expense text.

You can revoke this consent at any time in FinancePilot. Revocation stops further Ask sends to the provider selected for that request, and blocks further autonomous preparation. It does not delete copies already retained under Google’s or FinancePilot’s applicable retention limits. You may also request deletion of FinancePilot beta account and workspace data as described in §5.

This beta feature may be limited to explicitly enrolled accounts. Real-expense model transmission is disabled unless FinancePilot’s servers are separately configured to allow it.

3B. AI Coworker

Attorney review required. This section describes the implemented AI Coworker. It is not a determination that the processing is lawful, that OpenAI’s terms have been accepted for this use, or that a particular retention setting is in force.

When you are enrolled, have given consent, and set a trip to Auto with an active standing delegation, FinancePilot can send expense and evidence fields to OpenAI through a FinancePilot server. The server selects the model (currently GPT-4.1 mini). The app does not let the model choose a different provider. FinancePilot has not verified an OpenAI “do not train” or zero-retention setting for this call. Do not treat this notice as that verification.

The model can investigate trips and expenses and can request a supported change. FinancePilot’s server, not the model, decides whether the change is allowed. The only autonomous changes this beta can persist are:

  • adding a business purpose that is bound to your statement or to evidence already stored for that expense
  • classifying an expense as business or personal when the stored evidence supports that classification

The model must not invent an amount, a currency, a receipt, or a business purpose. A tool result can include a short excerpt of stored email or receipt text, such as a subject, snippet, preview, or summary. Email addresses in that excerpt are redacted. The result does not include the receipt image or the full mailbox. That excerpt is evidence. It is not an instruction that can override your account, your operating mode, or the server’s rules.

AI Coworker does not submit a report to Concur, change an amount, clear a trust hold, or permanently delete expenses, receipts, reports, or your account. Preparing a reviewable report, including an incomplete report that lists exceptions, is not a submission.

Manual does not send a model call. Assist can investigate and does not autonomously write. Auto can write only when enrollment, consent, a standing grant, the trip scope, the action type, the operation budget, and the server write switch all allow it. A standing grant alone is not permission. A global emergency stop turns autonomous writes off for every account.

You can revoke consent and delegation in FinancePilot. Revocation stops further model calls and further autonomous changes for that authorization. It does not by itself erase prior audit records or prior expense evidence.

Enrollment is an explicit list of accounts and trips. Turning on AI Coworker for one tester does not turn it on for every FinancePilot account.

4. Where information is kept

Imported expense, evidence, trip, and report information may be stored in the user’s FinancePilot workspace.

Current beta Gmail authorization credentials are maintained on the user’s device. Google sign-in token values stay on-device (secure storage such as iOS Keychain) and are not stored as token values on FinancePilot servers. Mailbox connection metadata (for example, connected account identity and sync status) may still be stored with the user’s FinancePilot workspace.

Current beta Microsoft authorization credentials (access and refresh tokens) are maintained on the user’s device in secure storage, the same class of on-device storage used for Gmail tokens (such as iOS Keychain). Token values are not stored in FinancePilot’s Outlook account records. Those records may still include mailbox identity, display name, authorization status, sync timestamps, and an opaque reference to the on-device token storage.

Consent records for optional AI processing, Action Framework audit records, and related preparation activity may also be stored with the user’s FinancePilot workspace when those features are enabled for the account.

5. Disconnecting access and requesting deletion

Revoking or disconnecting Google access prevents future Gmail access. It may not automatically delete previously imported FinancePilot workspace data.

In FinancePilot, pausing sync or removing a Gmail account stops future import from that account in the app. Those in-app actions do not by themselves revoke Google’s authorization. Users can revoke FinancePilot’s Google access in their Google Account permissions.

Outlook / Microsoft 365

In FinancePilot, disconnecting Outlook deletes the on-device Microsoft tokens for that mailbox, marks the mailbox inactive, and clears that mailbox’s on-device Outlook calendar cache. Existing imported expenses are kept. Disconnecting does not by itself revoke Microsoft’s authorization. Users can revoke FinancePilot’s Microsoft access in their Microsoft account permissions.

Revoking or disconnecting Microsoft access prevents future Outlook access. It may not automatically delete previously imported FinancePilot workspace data.

Optional AI consent

Revoking optional AI / coworker consent in FinancePilot stops further model sends and further autonomous preparation for that consent. It may not by itself delete previously imported workspace data, prior audit records, or copies a model provider has already retained. Gemini handling is described in §3A. AI Coworker handling is described in §3B. Neither section states a verified provider retention period.

Ordinary removal of an expense hides it from active reports and keeps the associated receipt recoverable by that account for 30 days. That window is configurable on the server. After it ends, the app will not restore the expense. An authorized cleanup job then removes the receipt file and the recovery record. That job is not a backup, and it does not delay an explicit permanent deletion or deletion of the whole account. Permanent deletion asks the user to sign in again; a refreshed session is not enough. AI Coworker cannot make either request. A database backup, if the operator has one, is not a promise that a deleted receipt can be restored. Attorney review required before this retention sentence is given to a tester.

Users may request deletion of FinancePilot beta account and workspace data at financepilot.betatest@gmail.com.

6. Service providers

FinancePilot may use infrastructure and storage providers (including Supabase) and AI service providers. Google Gemini is described in §3A and for receipt extraction. OpenAI is described in §3B for AI Coworker. Those sections are not a completed processor agreement. Providers are used as necessary to provide the service. Authorized preparation changes are executed by FinancePilot’s server under your consent and the controls in §3A and §3B. The model provider does not receive a direct write to your expenses.

Apple’s speech recognition service may process voice audio when you use push-to-talk, as described in §2. FinancePilot does not send that recording to OpenAI or to Google Gemini.

7. Security

FinancePilot uses account authentication, user-scoped access controls, and server-side handling of model API credentials for receipt extraction, Ask FinancePilot, and AI Coworker. This notice does not claim a specific encryption standard, geographic processing region for FinancePilot infrastructure, or certification beyond what is stated here.

8. Changes

Material privacy changes should result in an updated policy. Because FinancePilot is prerelease software, practices and features may evolve.
